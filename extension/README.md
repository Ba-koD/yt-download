# yt-download 확장 (실험 중)

유튜브 영상 페이지에 구간 편집 패널을 얹어, 고른 구간만 mp4 하나로 받습니다.
데스크톱 앱 없이 브라우저 안에서 전부 처리합니다.

## 설치

Chrome 웹 스토어에는 올릴 수 없습니다(유튜브 이용약관이 다운로드를 금지합니다).
직접 로드해서 씁니다.

1. `chrome://extensions` 를 엽니다
2. 오른쪽 위 **개발자 모드**를 켭니다
3. **압축해제된 확장 프로그램을 로드**를 누르고 이 `extension` 폴더를 고릅니다
4. 유튜브 영상 페이지를 열면 오른쪽 아래에 패널이 나타납니다

## 쓰는 법

- **현재 위치 IN / OUT** — 재생 중인 지점을 시작/끝으로 잡습니다
- 시간 칸을 직접 고치면 미리보기도 그 지점으로 옮겨갑니다
- 화질을 고르고 **구간 받기**를 누르면 mp4 파일로 저장됩니다

## 어떻게 동작하나

```
페이지에서 VISITOR_DATA 읽기
   ↓
InnerTube(ANDROID_VR 클라이언트)에 물어보기 → 포맷별 직접 주소
   ↓
색인(sidx) 2KB 만 받아서 "시간 → 바이트" 표 만들기
   ↓
고른 구간에 걸치는 조각만 Range 로 받기 (동시 6개)
   ↓
영상·소리 트랙을 mp4 하나로 엮기 (재인코딩 없음)
```

실제 요청은 배경 일꾼이 대신 합니다. content script 에서 곧바로 googlevideo 를 부르면
교차 출처로 막히기 때문입니다(같은 출처인 InnerTube 는 되는데 미디어만 실패하는 증상).

웹 클라이언트로 물어보면 유튜브가 주소를 주지 않습니다(SABR 로 넘어갔습니다).
`ANDROID_VR` 클라이언트는 아직 주소를 그대로 주고, 속도 제한용 `n` 파라미터도 붙지 않아
서명 해독이 필요 없습니다. **여기가 가장 먼저 깨질 곳입니다** —
받아지지 않으면 `src/innertube.js` 의 `CLIENT` 를 먼저 의심하세요.

## 지금 한계

| | 상태 |
|---|---|
| mp4 화질 (H.264 / AV1) | 됨. 4K 포함 |
| webm 화질 (VP9) | 안 됨 — 색인 방식이 달라 아직 못 읽습니다 |
| 진행 중인 라이브 · 지난 라이브 | 안 됨 — 조각(`&sq=N`) 방식이라 색인이 없습니다. 데스크톱 앱을 쓰세요 |
| 자르는 정확도 | 앞으로 몇 초 여유가 붙습니다(영상은 키프레임에서만 잘립니다). 소리는 영상에 맞춰 실제로 잘라내므로 어긋나지 않고, 편집 목록(elst)을 존중하는 재생기에서는 정확히 나옵니다 |
| 비공개·연령 제한 영상 | 안 됨 — 로그인 쿠키를 쓰지 않습니다 |
| 저장 방식 | 통째로 메모리에 담았다가 저장합니다. 아주 긴 구간은 무리입니다 |

4K 는 AV1(mp4)로 받습니다. VP9(webm)만 있는 영상은 목록에 나오지 않습니다.

## 검사

```bash
deno test --allow-read extension/test/
```

실제 유튜브가 준 `sidx` 바이트를 픽스처로 두고 색인 해석을 확인합니다.
